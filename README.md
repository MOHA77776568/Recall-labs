# Recall Labs

نسخة محلية من واجهة Recall Lab تعمل على Windows أو في المتصفح على `localhost`، مع مزامنة يدوية للبيانات عبر GitHub وتحديث برنامج Windows من داخل التطبيق.

حُفظت ملفات واجهة الموقع الأصلي `https://recall-lab.moha77776568.chatgpt.site` داخل المشروع لتعمل محليًا، مع استبدال خدمة الحفظ بمخزن محلي. **بيانات حسابك السابق لم تُنقل:** تتطلب الخدمة الأصلية تسجيل الدخول بحساب ChatGPT. انقلها بواسطة تصدير JSON من الموقع ثم استيراده في الواجهة المحلية. يبدأ التطبيق ببيانات فارغة حتى تضيفها أو تستوردها. تفاصيل مصدر الملفات وبصماتها في [SOURCE.md](renderer/site/SOURCE.md).

## التشغيل على Windows

ثبّت [Node.js LTS](https://nodejs.org/) بإصدار 22 أو أحدث. نزّل هذا المستودع من GitHub باستخدام **Code → Download ZIP** وفك الضغط، أو استنسخه بواسطة Git. افتح PowerShell داخل مجلد المشروع:

```powershell
npm ci
npm start
```

للاستنساخ مباشرةً من فرع `main` عند توفر Git:

```powershell
git clone --branch main https://github.com/MOHA77776568/Recall-labs.git
cd Recall-labs
npm ci
npm start
```

استخدم `npm ci` مع ملف القفل المرفق حتى تُثبت النسخ المحددة؛ لا تحتاج إلى تحديث الاعتماديات لبدء التشغيل.

لتشغيل نسخة المتصفح:

```powershell
npm run web
```

افتح `http://localhost:4173`. اترك نافذة الأوامر مفتوحة أثناء الاستخدام. التطبيق يعمل دون إنترنت بعد تثبيت الاعتماديات؛ المزامنة والتحديثات تتطلب الوصول إلى GitHub.

لإنشاء مُثبّت Windows محليًا:

```powershell
npm run dist:win
```

الملفات الناتجة في `dist/`. إصدار NSIS ذو الامتداد `.exe` هو المسار الموصى به للتثبيت والتحديث داخل التطبيق؛ ملف `.zip` بديل للتشغيل اليدوي. الإصدارات الأولية غير موقّعة ما لم يضف المسؤول شهادة توقيع، وقد يعرض Windows تحذير SmartScreen.

## البيانات والمزامنة

يُحفظ عملك محليًا. افتح إعدادات GitHub في التطبيق؛ الإعداد الافتراضي هو:

```text
Repository: MOHA77776568/Recall-labs
Branch: main
Path: data/workspace.json
```

افتح **GitHub sync & app updates** من شريط الواجهة، احفظ إعداداتك ثم اضغط **مزامنة الآن** لاستقبال البطاقات الجديدة ومشاركة بياناتك وتقدم المراجعة بين الأجهزة. للكتابة، أنشئ **Fine-grained personal access token** للمستودع المختار فقط بصلاحية **Contents: Read and write**، وأدخله في التطبيق. لا ترسله في المحادثة أو تضعه في ملفات المشروع. ربط GitHub بهذه المحادثة لا يسجّل دخول تطبيقك المحلي تلقائيًا. القراءة من مستودع عام متاحة دون رمز.

في Electron يُحمى الرمز بواسطة تشفير Windows المتاح عبر `safeStorage`. في نسخة المتصفح يبقى الرمز في الذاكرة فقط ويجب إدخاله مجددًا بعد إعادة تحميل الصفحة. عند التعارض اختر النسخة الصحيحة لكل عنصر؛ احتفظ بتصدير JSON احتياطي قبل تغييرات كبيرة. مستودع `Recall-labs` الحالي **عام**، فتظهر البيانات وتقدم المراجعة المتزامن لأي شخص. الكتابة إلى مستودع عام تحتاج موافقة صريحة داخل الإعدادات، ونوصي بمستودع بيانات خاص للمحتوى الشخصي.

تتضمن المزامنة بيانات المجموعات والمحاضرات والبطاقات والمراجعات. ملفات المرفقات، مثل PDF، تبقى محلية ولا تنتقل عبر ملف JSON؛ انقلها إلى الجهاز الآخر بشكل منفصل عند الحاجة.

راجع [المزامنة والخصوصية](docs/sync-and-security.md) و[السماح بالاتصال والتحديثات](docs/windows-and-updates.md) لتفاصيل الإعداد مع Cold Turkey. لإضافة بطاقات بواسطة مساعد أو نموذج آخر، اتبع [تنسيق البيانات](docs/data-format.md).
