# Windows، الاتصال والتحديثات

## البداية

استخدم `npm ci` ثم `npm start` أثناء التطوير. بعد توفر إصدار منشور، نزّل مُثبّت `.exe` من صفحة Releases في GitHub؛ لا يحتاج المستخدم النهائي إلى Node.js. تدعم نسخة `localhost:4173` التشغيل في المتصفح، لكن تثبيت تحديث برنامج Windows يحتاج نسخة Electron المثبّتة.

احتفظ بتصدير JSON للبطاقات قبل تغيير جهازك أو حذف ملفات التطبيق. تنزيل إصدار جديد وحده لا ينقل بيانات متصفح سابق؛ استورد ملف التصدير أو استخدم المزامنة مع GitHub.

## إعداد Cold Turkey

أضف هذه النطاقات إلى المواقع المسموح بها وفق إعدادات الحظر الخاصة بك. لا يحتاج التطبيق إلى تعطيل الحظر:

| النطاق | الغرض |
| --- | --- |
| `localhost` و`127.0.0.1` | نسخة المتصفح المحلية؛ المنفذ الافتراضي `4173` |
| `api.github.com` | قراءة البيانات، كتابتها، والتحقق من الإصدارات |
| `github.com` | صفحة المستودع والإصدارات وروابط التنزيل |
| `release-assets.githubusercontent.com` | تنزيل ملفات الإصدار |
| `objects.githubusercontent.com` | ملفات GitHub بعد إعادة توجيه التنزيل |
| `raw.githubusercontent.com` | الوصول إلى ملفات المستودع الخام عند الحاجة |

أثناء الإعداد والبناء فقط، قد تحتاج أيضًا إلى `nodejs.org` لتنزيل Node.js و`registry.npmjs.org` لاعتماديات npm. تنزيل Electron وأدوات بناء Windows قد يستخدم نطاقات GitHub أعلاه. إذا أظهر سجل أداة البناء نطاقًا إضافيًا، راجعه وأضفه بنفسك إن رغبت؛ لا تُلغِ التحقق من TLS أو توقيع الحزم أو البصمات.

إضافة GitHub إلى Cold Turkey لا تُدخل بيانات دخول إلى التطبيق. استخدام API أو رابط تنزيل قد يمر بإعادة توجيه إلى نطاق آخر في الجدول. عند فشل التنزيل راجع النطاق المحظور الذي يعرضه برنامج الحظر.

## التحديث من داخل التطبيق

الإعداد الافتراضي يبحث عن إصدارات منشورة في `MOHA77776568/Recall-labs`. من شريط الواجهة افتح **GitHub sync & app updates**، ثم **فحص التحديثات** و**تنزيل التحديث** و**تثبيت وإعادة التشغيل** عند توفر إصدار أحدث. التحديثات البرمجية منفصلة عن زر مزامنة البيانات. تشغيل المصدر بواسطة `npm start` لا يُحدَّث ذاتيًا؛ حدّث ملفات المصدر وأعد تنفيذ `npm ci`، أو استخدم المُثبّت.

يستخدم مسار التحديث بيانات التحقق التي يولّدها `electron-builder` مع ملفات الإصدار، بما فيها بصمة SHA-512 في `latest.yml`. لا تحذف هذا الملف أو تعدّل بصماته يدويًا. البصمة تكشف تلف التنزيل، لكنها لا تعوّض شهادة توقيع Windows ولا تحمي من اختراق حساب النشر؛ فعّل المصادقة الثنائية واحمِ صلاحية نشر الإصدارات.

الإصدار غير الموقّع قد يثير SmartScreen. تحقّق من أن الملف آتٍ من المستودع المتوقع قبل تشغيله. التوقيع بشهادة موثوقة يحتاج إعدادًا منفصلًا، ولا يوجد وعد بأن النسخة الأولية موقّعة.
