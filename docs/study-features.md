# استخدام تتبّع الدراسة والإحصاءات والصور

هذه الميزات في نسخة المصدر 0.2.0. ملف التثبيت المنشور سابقًا 0.1.0 لا يحتويها. فرع التطوير قابل للمراجعة، ولا يُنشر إصدار تلقائيًا عند تشغيل الاختبارات أو بناء حزمة المراجعة.

## المشاهدة والتفريغ

من **Sources** اضغط **Log viewing / سجّل مشاهدة** على المحاضرة، أو افتح **Study tracking**. مشاهدة كاملة اليوم تحتاج تأكيدًا وحفظًا؛ افتح التفاصيل فقط لتسجيل أجزاء محددة أو تاريخ سابق أو سبب أو ملاحظة أو وقت اختياري. يمكنك استئناف مرور غير مكتمل، أو بدء مرور جديد، أو تسجيل مراجعة جزئية مستهدفة.

المرور هو مشاهدة مقصودة للمحاضرة؛ الجلسة هي جلوس واحد. الأجزاء 0–20 و20–40 و40–60 لمحاضرة مدتها 60 دقيقة تكمل مرورًا واحدًا في ثلاث جلسات. التغطية تحسب اتحاد الأجزاء؛ 0–20 و10–30 تعني 30 دقيقة. الاكتمال التلقائي يحتاج تغطية **100%** من مدة معروفة، ويمكن تأكيد الاكتمال يدويًا. عدد المشاهدات القديمة التقريبي يُسجّل كخط أساس بلا جلسات أو تواريخ مختلقة، ويُستثنى من إحصاءات الفترة.

في **Lecture plan** حدّد مدة المحاضرة إن كانت معروفة، واختر التفريغ الكامل أو مقاطع محددة أو **Not planned**. سجّل عملك على الورق أو في تطبيق آخر دون رفع النص. افصل النقل الحرفي عن الكتابة بأسلوبك وعن الكتابة من الذاكرة. سجّل المقاطع **Written** أو **Verified** بعد مقارنتها بالمصدر؛ المتحقق يدخل ضمن المكتوب ويُعرض أيضًا منفصلًا. النسب تعتمد مدة المحاضرة أو اتحاد المقاطع المستهدفة، ولا تظهر نسبة إذا كان المقام مجهولًا.

**Continue from here** يفتح أول فجوة غير مكتوبة. تعديل عمل سبق التحقق منه يحتاج تحققًا جديدًا؛ حذف مقطع أو تصحيحه لا يعيد احتساب تحقق أقدم تحته. عند تداخل حالات مختلفة تعتمد الحالة الحالية أحدث `modifiedAt`، مع ترتيب ثابت عند التعادل. حذف/تحريك مقطع يقتطع نطاقه القديم من الحالات الأقدم حتى لا تظهر تغطية قديمة من جديد. يمكنك التراجع عن الحذف أو التعديل ما لم يحدث تعديل أحدث للعنصر نفسه.

الجلسة المشتركة يمكن أن تحمل المشاهدة والتفريغ معًا؛ 45 دقيقة اختيارية تُحسب مرة واحدة في إجمالي الجهد، وتظهر الجلسة تحت كل طريقة مرتبطة بها. تحميل PDF مرجعي لا يسجل تفريغًا يدويًا تلقائيًا.

## الإحصاءات والأدلة

افتح **Statistics / الإحصاءات**. التبويبات هي Overview وActivity وRecall وEvidence وComparisons وSchedule. المرشحات تشمل الفترة والمقرر والمحاضرة والمفهوم/الوسم. تُخزن اللحظات UTC ويكون التقويم الافتراضي **Asia/Amman**؛ يمكن تغييره داخل الإحصاءات. تُعرض التغطية الحالية والمواعيد الحالية بوصفها حالة حالية، ويُطبق مرشح الفترة على الجلسات والنتائج المؤرخة.

المراجعة المؤجّلة ذاتية التقييم تستخدم أول مراجعة مؤهلة لكل بطاقة في اليوم المحلي: مراجعة مغلقة المصدر، مع حالة Review معروفة قبل الإجابة، ومراجعة سابقة معروفة قبل 24 ساعة على الأقل. **Again** فشل استرجاع، وHard/Good/Easy نجاح استرجاع بدرجات صعوبة مختلفة. نجاحات إعادة التعلم في اليوم نفسه لا تحوّل أول فشل مؤهل إلى نجاح. هذا ليس دقة امتحان موضوعية أو تعريف Anki الدقيق لـTrue Retention. تظهر البسط والمقام وحجم العينة والتاريخ والسجلات المساهمة؛ التاريخ القديم غير المؤهل يبقى تاريخ مراجعات عامًّا.

في المراجعة افتح **Optional review context** قبل الكشف إذا أردت تسجيل ثقة اختيارية أو اختيار جلسات دراسة سابقة مرتبطة. لا تُسجّل ثقة بأثر رجعي، ولا يستنتج التطبيق الطريقة من تلقاء نفسه. تبقى نتائج الطرق وصفية ورصدية؛ الطرق المختلطة تظل مختلطة ويظهر تأخر الاختبار والسياق المتاح، دون إعلان طريقة فائزة أو نسبة تحسن مضمونة.

أول حفظ فعلي لمسودة استرجاع جديدة غير فارغة يسجل محاولة بتاريخ الحفظ. تعديل المسودة لاحقًا يبقى انعكاسًا على المحاولة ولا ينشئ محاولة أخرى. المسودات القديمة المستوردة لا تحصل على تواريخ محاولات مختلقة. اضغط **Assess this attempt** من محرر الاسترجاع لتعديل المحاولة ذاتها وإضافة قائمة أفكار متوقعة. في Evidence يمكنك أيضًا تسجيل محاولة مستقلة أو مفهوم أو فجوة أو دليل شرح/مثال/تطبيق. قيّم الفكرة كصحيحة أو جزئية أو مفقودة أو خاطئة؛ **Not assessed** يبقى غياب تقييم. دون قائمة متوقعة صريحة لا توجد نسبة تغطية أفكار.

يمكن للفجوة أن تكون Open أو Addressed أو Rechecked مع تواريخ ودليل. كثرة المشاهدة أو الكلمات أو حالة checked أو مدة FSRS لا تعني إتقانًا. البطاقة المتكررة النسيان تُقترح عند 3 تقييمات Again على يومين محليين على الأقل خلال آخر 30 يومًا، بالتقاطع مع الفترة المحددة. **Worth your attention** يعرض السبب وروابط إجراءات يمكن تجاهلها أو إخفاؤها؛ لا يغير الجدولة ولا يفرض دراسة.

## صور البطاقات وإخفاء المناطق

افتح **Images & occlusion / الصور** ثم **New image card**، أو عدّل بطاقة قديمة من Flashcards لتظهر أدوات الصور داخل محررها. اختر **Add to** للسؤال أو الجواب، ثم الصق Screenshot بـCtrl+V أو ارفع ملفات أو اسحبها إلى منطقة الإدخال. يدعم PNG وJPEG وWebP ثابتة، مع عدة صور مرتبة ووصف اختياري وتقديم/تأخير واستبدال وإزالة. يكفي أن يحتوي كل وجه نصًا أو صورة أو إخفاءً صالحًا. الحفظ ينتظر اكتمال حفظ الصور المحلية.

في الدراسة تُكشف صور الجواب بعد **Reveal answer** فقط، ويمكن تكبير الصور دون تغيير أبعادها النسبية. ملفات JPEG ذات تدوير EXIF تُعرض بأبعادها المرئية دون إعادة كتابة الأصل. النصوص العربية والإنجليزية والمعادلات تبقى مدعومة.

لإخفاء أجزاء صورة، أضفها إلى السؤال واختر **Image to cover**. ارسم مستطيلًا بـ**Draw a region**، أو أضفه بالحقول الرقمية. اسحبه للتحريك، واستعمل المقبض السفلي لتغيير حجمه، أو عدّل نسب موضعه وحجمه بلوحة المفاتيح. اختر المنطقة المستهدفة و**Hide the other regions too** عند الحاجة، ثم راجع معاينتي السؤال والجواب. الإحداثيات نسبية إلى الصورة الأصلية، وتبقى بمحاذاتها عند التكبير أو تغيير عرض النافذة.

**Generate one card per region** يولّد بطاقة FSRS مستقلة لكل منطقة مع ملف صورة مشترك. إعادة التحرير أو التوليد للمناطق الموجودة تحافظ على معرّفات بطاقاتها وجدولتها؛ لا تصفر التقدم. إزالة مرجع صورة لا تحذف الملف المشترك من الجهاز أو GitHub.

## المزامنة والنسخ الاحتياطية

إعدادات المستودع والفرع والمسار المحفوظة لا تتغير تلقائيًا. استخدم مستودع البيانات الخاص `MOHA77776568/Recall-labs-data` عند الحاجة لإعداد جهاز جديد. يحتاج الرمز Contents read/write لهذا المستودع فقط. صور البطاقات تُرفع إلى مستودع **خاص** فقط حتى إذا كانت الموافقة على مزامنة JSON إلى مستودع عام مفعّلة.

مع `data/workspace.json` تحفظ الصور في `data/media/<sha256>.<ext>`؛ المسار يتبع مجلد ملف JSON الفعلي إذا غيرته. SHA-256 يمنع تكرار الملف نفسه. يُتحقق من النوع والبنية والحجم والبصمة؛ لا يُخزَّن Base64 في workspace.json. يُرفع الاعتماد الثنائي قبل رفع تغييرات JSON، وتُنزل الصور الناقصة للجهاز الآخر. فشل النقل يبقى حالة جزئية مع رسالة و**Sync** لإعادة المحاولة؛ السجلات والملفات التي وصلت تبقى محفوظة. الصورة الغائبة تظهر برسالة ويمكن استعادتها بالمزامنة أو باستبدالها بملفها الأصلي.

من شاشة الصور استخدم **Full backup with images** لتصدير ZIP يحتوي workspace.json وملفات الصور المشار إليها. **Restore full backup** يستعيدها بعد التحقق من جميع المسارات والبصمات وقبل تغيير مساحة العمل. ملفات JSON العادية تحتوي البيانات ومراجع الصور فقط. مرفقات المحاضرات الأصلية PDF/TXT وغيرها تبقى محلية ومستقلة عن مزامنة صور البطاقات وعن ZIP الصور.

الحدود: الصورة 10 MiB، البعد 20,000 بكسل، مجموع 40 مليون بكسل؛ ملف المزامنة 10 MB؛ ZIP الكامل 64 MiB. الصور المتحركة وSVG غير مدعومة في هذه الإضافة. لن ينتج تصدير كامل يدّعي النجاح إذا كانت صورة مطلوبة مفقودة.

## الترحيل والتشغيل

ترحيل schema 2 / workspace 1 إلى **schema 3 / workspace 2** آمن ومتكرر بلا ازدواج. يُحتفظ بالأصل في النسخ المحلية قبل الترحيل، وتبقى المعرفات وجدولة FSRS والتاريخ والملاحظات والامتدادات الآمنة. تبقى القياسات الجديدة غير مسجلة حتى تسجلها. حدّث الجهازين قبل مزامنة التنسيق الجديد؛ النسخ القديمة ترفضه لحماية السجلات الجديدة من الإسقاط.

لتشغيل نسخة المصدر من هذا الفرع على Windows:

```powershell
git clone --branch codex/study-progress-statistics https://github.com/MOHA77776568/Recall-labs.git
cd Recall-labs
npm ci
npm start
```

بديل المتصفح: `npm run web` ثم `http://localhost:4173`. مصدر الواجهة المضاف مقروء؛ `npm run ui:integrate` يعيد دمجه مع نسخة vendor محلية مقفلة البصمة، و`npm run ui:check` يتحقق من قابلية إعادة الإنتاج. لا توجد CDN أو API ذكاء اصطناعي أو خدمات تحليلات أثناء الدراسة.

تبني اختبارات PR حزمة Windows في **Actions → Tests → Artifacts → recall-labs-windows** دون إنشاء إصدار. فك ضغط artifact وشغّل ملف .exe؛ ملفات الإصدار العام والتحديث الداخلي لا تتغير حتى مراجعة التغيير ودمجه ونشر إصدار لاحق بشكل صريح.
